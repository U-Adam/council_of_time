# Council of Time — UI, UX, CSS, and Semantic Integrity Audit

Date: 2026-09-16

## Finding

The product had a strong visual direction but the implementation accumulated overlapping style generations. Core components such as the composer, brand masthead, buttons, response typography, and About panels were redefined across multiple stylesheets with `!important` overrides. The same drift appeared semantically in the runtime Artist Witness rule: the Worker forced a witness into every substantive table even though the project method requires relevance and genre discipline rather than decorative participation.

## Refactor

- Consolidated the visual system into semantic tokens plus dedicated base, home, conversation, and About layers.
- Removed the legacy override stack and public `brand.css` override.
- Established the "Archival Future" visual direction: institutional editorial typography, warm brass accents, restrained geometry, evidence-led metadata, and minimal motion.
- Rebuilt the homepage hierarchy around seal → Council name → mission → illuminated question console.
- Restyled suggested questions as archival prompts rather than app cards and About as editorial navigation.
- Made Council responses read as deliberative records rather than chat bubbles, preserving responsive evidence tables, citations, provenance badges, Fault Line states, and source ledgers.
- Reworked the About page toward an institutional catalogue/museum-index presentation.
- Added a persistent light/dark appearance control, first-visit system preference, pre-hydration initialization, and shared semantic theme tokens.
- Retained 44px touch targets, visible focus behavior, reduced-motion handling, mobile table transformations, and safe-area support.
- Changed Artist Witness routing from mandatory to relevance-driven.
- Brought Jordan Peele and Mac Miller into the runtime source registry in alignment with the current Project Sources, which already document both witnesses.

## Design principle

The seal is the historical object. The interface is the modern instrument. The writing and traceable source apparatus carry the authority.
