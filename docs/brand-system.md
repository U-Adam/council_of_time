# The Council of Time — Brand Asset System

## Core idea

The seal is the historical object. The interface is the modern instrument. The writing and source apparatus carry the authority.

The visual system should feel archival, editorial, precise, and contemporary without becoming faux-antique, steampunk, dark-academia decoration, or generic AI futurism.

## Assets

- `council-mark.svg` — primary witness seal; full-detail institutional mark.
- `council-mark-small.svg` — simplified small-format mark for favicon/PWA contexts.
- `council-wordmark.svg` — wordmark with the project line, *A serious table for difficult questions.*
- `council-lockup-horizontal.svg` — primary horizontal seal + wordmark lockup.
- `council-mark-archival.svg` — one-color ink treatment for print, citations, documents, and archival contexts.
- `council-mark-relief.svg` — restrained embossed/debossed ceremonial treatment.
- `council-watermark.svg` — transparent line-art mark for low-opacity page backgrounds.
- `social-share.png` — social preview image; preserve as the canonical raster share asset unless deliberately replaced.

## Color

Primary institutional palette:

- Ink: `#100f0d`
- Ivory: `#efe6d8`
- Brass: `#b99249`
- Bright brass: `#d4a84f`
- Rust: reserved for Fault Line / interruption states

Light-mode colors are semantic adaptations rather than inverted dark-mode values. Gold must remain legible and visibly intentional against parchment.

## Typography

- Display / wordmark: classical editorial serif, upright. Do not italicize “of.”
- Reading: book serif optimized for long-form deliberation.
- Interface: modern system sans.
- Provenance / metadata: restrained monospace.

No single typeface needs to perform the entire ancient-to-modern concept. The contrast among these roles creates the temporal range.

## Usage

The primary seal should remain visually intact and should not be stretched, recolored arbitrarily, given neon glows, or placed inside extra decorative containers. Use the watermark asset for background scale rather than lowering the opacity of the dark-filled primary mark.

The small mark is intentionally simplified; use it below roughly 48 CSS pixels. The horizontal lockup is for wider editorial/press contexts. The archival and relief treatments are secondary renderings, not alternate logos.
